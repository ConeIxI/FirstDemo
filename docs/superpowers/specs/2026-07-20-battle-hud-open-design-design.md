# 战斗 HUD Open Design 设计

## 目标

为 16:9 PC 画面设计一套写实中世纪风格的玩家战斗 HUD。界面常驻显示玩家生命、稳定、战意、四个可用道具、三个技能以及当前装备武器，同时保持屏幕中央的战斗视野完整。

本设计仅产出可预览的 Open Design 视觉稿，不直接改动 Unity 场景、Prefab 或运行时代码。

## 视觉方向

- 风格：写实中世纪，低饱和、克制的信息面板。
- 基色：半透明石墨灰；边框使用暗金色金属；局部采用轻微磨损纹理。
- 状态色：生命为暗红，稳定为灰蓝，战意为琥珀黄。
- 信息表达：状态条、图标、键位与数值具有明确层级，不使用厚重背景块或侵占中央画面的装饰。

## 总体布局

采用角落分区 HUD（方案 A）。各模块距离屏幕边缘保持约 3% 的安全区，所有常驻信息留在左上、左下和右下区域。

```text
+--------------------------------------------------------------+
|  生命 / 稳定 / 战意                                           |
|  状态条（左上）                                               |
|                                                              |
|                         战斗画面                              |
|                                                              |
|  [道具 1][道具 2][道具 3][道具 4]   [技能 Q][技能 E][技能 R][武器] |
+--------------------------------------------------------------+
```

## 组件规格

### 玩家状态区

- 位于左上，宽度约为屏幕宽度的 18%。
- 从上到下排列生命、稳定、战意三条进度条。
- 每条都包含属性图标、属性名称、彩色进度条和 `当前值 / 最大值` 数值。
- 设计稿使用示例值：生命 `72 / 100`、稳定 `45 / 80`、战意 `60 / 100`。

### 道具区

- 位于左下，四个等大的方形槽位水平排列。
- 每个槽位左上角显示快捷键 `1` 至 `4`，右下角显示道具数量。
- 当前选中的道具使用暗金描边；未装备槽位保留空框。

### 技能与武器区

- 位于右下，三个技能槽水平排列，后接一个更宽的武器栏。
- 技能槽快捷键固定为 `Q`、`E`、`R`。
- 武器栏展示当前装备武器的图标、名称和耐久或弹药类数值。
- 不包含普攻、闪避或其他固定动作键。

## 战斗反馈

- 生命值变化采用快速平滑过渡，受击时状态条短暂闪红。
- 稳定值临界时，灰蓝条产生轻微抖动。
- 战意满值时，琥珀黄边框出现克制的脉冲提示。
- 道具使用后立即更新数量；道具冷却显示低对比度扇形遮罩。
- 技能冷却使用顺时针遮罩和剩余秒数；可释放时显示完整图标和键位；资源不足时整体降亮度。
- 武器切换只播放短促边框亮起和图标替换，不弹出大面积提示。

## Open Design 产出与验收

Open Design 应生成一张 16:9 的战斗 HUD 预览稿，包含如下可见元素：

- 左上三条有示例数值的状态条。
- 左下四个含键位与数量的道具槽。
- 右下三个技能槽及一个武器栏。
- 模拟战斗场景作为背景，以验证 HUD 不遮挡中央战斗区域。

验收标准：三种状态的颜色和数值易读；四个道具槽、三个技能槽和一个武器栏数量准确；整体风格符合低饱和写实中世纪方向；中央战斗区域不被常驻面板遮挡。
