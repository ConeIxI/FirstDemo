# 武士刀后跳突刺技能图标设计

## 目标

生成一张 128×128 PNG 技能图标，以白色单人剪影表现“挥砍后跳，落地蓄力并准备向前突刺”的连续动作，保存到 `Assets/Res/UI/Atlas/Skill`。

## 构图

- 采用后跳落地后的低身蓄力瞬间，人物重心后压，前腿屈膝支撑。
- 武士刀收至身体侧后方，刀尖朝向前方，形成即将突刺的明确方向。
- 人物身后保留一道弧形挥砍刀光和少量后跳动势线，用于交代前一阶段动作。
- 刀尖前方使用短促锐利的速度线，暗示下一阶段的向前突刺。
- 仅出现一个人物，不使用人物残影，不加入文字、边框、底板或场景元素。

## 视觉规格

- 画布：128×128 像素。
- 格式：PNG，透明背景，保留 Alpha 通道。
- 主体：纯白或接近纯白的高对比剪影，边缘清晰，适合小尺寸显示。
- 留白：主体与刀光控制在安全边距内，缩略显示时四肢、刀身和动作方向仍可辨认。
- 风格：简洁、凌厉、偏动作游戏技能图标，不使用灰色背景、发光底色或写实纹理。

## 验收标准

- 文件尺寸精确为 128×128。
- 背景透明，主体为白色剪影。
- 单个姿势能读出低身蓄力和向前突刺方向。
- 弧形刀光与后向动势能够补充表达此前的挥砍后跳。
- 画面中无文字、水印、多余角色或被裁切的关键轮廓。
