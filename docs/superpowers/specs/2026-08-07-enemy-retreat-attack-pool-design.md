# 敌人远离攻击池配置设计

## 背景

当前敌人战斗配置已经支持基础攻击池、进身攻击池、追击攻击池和反击攻击配置。Boss 战斗设计需要新增“远离攻击池”，用于表达近距离时主动拉开距离的攻击类动作，例如“攻击后撤”。

本次只补充敌人通用配置承载能力，不修改行为树，不接入处决逻辑，也不改变当前攻击选择流程。

## 范围

- 在敌人通用攻击配置中新增 `retreatAttacks` 字段。
- 字段语义为“主动远离目标的攻击技能池”，与 `basicAttacks`、`approachAttacks`、`pursuitAttacks` 平级。
- GreatSwordBoss 配置先保留空池，由后续技能配置或决策逻辑接入时再填充具体技能 ID。
- 纯后撤不放入该攻击池，后续如需支持应建模为独立通用后撤行为或战斗计划类型。

## 非目标

- 不改 Boss 行为树结构。
- 不改 `EnemyCombatDecisionController` 的攻击选择逻辑。
- 不接入处决。
- 不把受击闪避、防御反应复用为主动远离动作。

## 数据结构

`retreatAttacks` 使用现有攻击配置元素类型，保持与其他攻击池一致的序列化和编辑方式。配置消费者后续可以按距离、概率或战斗节奏从该池读取技能计划。

## 验收标准

- 敌人配置资源可以序列化 `retreatAttacks` 字段。
- `GreatSwordBossDefinition.asset` 包含 `retreatAttacks: []`。
- 当前行为不发生变化，因为尚未接入选择逻辑。
