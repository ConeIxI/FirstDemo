# 敌人战斗决策重构设计

- 状态：已确认
- 日期：2026-08-01
- 首个接入对象：剑盾敌人
- 配置迁移范围：全部近战敌人

## 1. 目标

将敌人战斗行为明确划分为对峙、攻击、追击、防御和闪避，并将攻击动作选择、攻击阶段和组合动作从行为树细节中拆出，由独立战斗决策器管理。

本次设计需要实现以下结果：

- 攻击欲望决定敌人进入攻击状态的频率；
- 玩家离开追击范围时，在稳定值满足条件的前提下强制产生攻击意图；
- 防御和闪避由玩家按下默认攻击键触发判定；
- 攻击支持基础动作加权选择、组合动作分支和逐段中止条件；
- 防御和闪避使用动画生命周期控制结束；
- 删除旧攻击选择与随机后撤配置，不保留兼容字段。

## 2. 范围

### 2.1 本次范围

- 剑盾敌人接入完整的新战斗决策流程；
- 全部近战敌人迁移到新的配置结构和输入触发闪避策略；
- 行为树继续负责高层状态优先级；
- 新增独立战斗决策器管理攻击运行状态；
- 更新配置校验、行为树资产和相关测试。

### 2.2 非目标

- 不修改对峙状态现有的 `CombatIdle -> MoveLeft/MoveRight` 表现；
- 不修改现有防御伤害、减伤或稳定值结算规则；
- 不新增基础动作的独立冷却、距离或条件配置；
- 不缓存攻击进行阶段收到的玩家攻击输入。

## 3. 战斗状态

战斗状态划分如下：

```text
对峙
攻击
├─ 追击
├─ 攻击起始
├─ 攻击进行
└─ 攻击结束
防御
闪避
```

### 3.1 对峙

- 维持现有 `CombatIdle` 行为；
- 现有逻辑继续随机播放 `MoveLeft` 或 `MoveRight`；
- 按攻击决策间隔进行一次攻击欲望检定；
- 检定失败后继续对峙，等待下一次决策窗口。

### 3.2 追击

- 追击是已产生攻击意图后的接近阶段，不是独立产生攻击的普通移动分支；
- 玩家不在敌人攻击范围内时播放 `Run` 并接近玩家；
- 进入攻击范围且玩家位于敌人前方后进入攻击起始阶段。

### 3.3 防御

- 只由有效的玩家攻击输入触发；
- 播放防御动画，动画结束后回到对峙；
- 防御期间被命中时进入中断层并播放 `DefenseHit`；
- 伤害和稳定值处理沿用现有防御结算。

### 3.4 闪避

- 只由有效的玩家攻击输入触发；
- 使用后撤闪避动画；
- 动画播放期间处于无敌状态，不受伤且不播放受击动画；
- 动画结束后清除无敌并回到对峙；
- 死亡或更高优先级中断提前结束闪避时也必须清除无敌。

## 4. 职责划分

### 4.1 行为树

行为树只管理以下职责：

- 战斗目标和战斗姿态前置条件；
- 闪避、防御、攻击和对峙的优先级；
- 调用对应行为节点并根据运行状态保持分支。

### 4.2 战斗决策器

独立战斗决策器负责：

- 攻击意图检定；
- 基础动作加权选择；
- 组合动作运行时字典构建；
- 组合分支概率选择；
- 当前攻击动作、组合路线和序列位置；
- 追击、攻击起始、攻击进行、攻击结束阶段推进；
- 玩家攻击输入的即时响应判定。

攻击动作选定后必须锁定，后续 `Tick` 不得重新随机。

### 4.3 黑板

黑板保存行为树需要观察的战斗事实：

- 当前战斗状态；
- 当前攻击阶段；
- 当前攻击意图；
- 当前目标、距离范围和可见性；
- 当前待执行的防御或闪避反应。

玩家攻击输入不跨攻击阶段缓存。只有在允许响应的状态收到输入后，才能生成一次待执行反应。

### 4.4 动画与战斗组件

- 动画组件负责播放动作并报告动画是否结束；
- 战斗组件负责启动技能、攻击判定和防御结算；
- 生命或受击系统负责无敌、受击和中断；
- 这些组件不参与概率选择。

## 5. 配置结构

### 5.1 决策参数

统一决策配置包含：

```text
attackDesire
attackDecisionCooldown
defenseRate
dodgeRate
dodgeCooldown
lowStabilityThreshold
```

剑盾敌人初始值：

```text
attackDesire = 0.65
attackDecisionCooldown = 1.2
defenseRate = 0.35
dodgeRate = 0.6
dodgeCooldown = 3.0
lowStabilityThreshold = 0.25
```

### 5.2 基础动作配置

每个基础动作包含：

```text
skillId
animationName
weight
```

剑盾敌人配置五个基础动作：

- 右劈；
- 左劈；
- 盾击；
- 蓄力重击；
- 蓄力突刺。

初始权重均为 `1`，运行时按总权重归一化选择。

### 5.3 组合动作配置

每个组合动作分支包含：

```text
startSkillId
sequenceSkillIds
branchProbability
```

`sequenceSkillIds` 不包含起始技能本身。剑盾敌人初始分支：

```text
右劈 -> 左劈 -> 盾击：0.5
右劈 -> 左劈 -> 蓄力突刺：0.5
```

运行时从序列化数组构建：

```text
Dictionary<int, ComboBranch[]>
```

键为起始技能 ID，值为该起始技能对应的全部组合分支。同一起始技能的分支概率在选择时归一化。

### 5.4 删除的旧字段

全局删除以下旧字段及对应逻辑，不保留兼容字段：

```text
firstAttackSkillId
normalComboSkillIds
skillWeights
retreatDesire
retreatCooldown
minSafeDistance
retreatDistance
defenseDuration
```

所有近战敌人必须迁移到新配置后再完成代码清理。

## 6. 攻击意图

攻击意图的硬前提是敌人稳定值比例不低于 `lowStabilityThreshold`。

```text
稳定值不足
    => 不产生攻击意图

稳定值满足
    且玩家位于追击范围外
        => 立即产生攻击意图

稳定值满足
    且玩家位于追击范围内
    且攻击决策冷却结束
    且攻击欲望检定通过
        => 产生攻击意图
```

攻击欲望检定失败后记录本次检定时间，继续对峙并等待下一个攻击决策窗口。追击范围外的强制攻击不受攻击欲望影响。

稳定值不足且玩家在追击范围外时，敌人保持对峙并朝向玩家；稳定值恢复后立即产生强制攻击意图。

## 7. 攻击流程

### 7.1 基础动作选择

产生攻击意图后，战斗决策器从基础动作配置中按权重选择一个动作并锁定。

### 7.2 追击阶段

- 玩家不在敌人攻击范围时，播放 `Run` 并接近玩家；
- 进入敌人攻击范围后检查玩家是否位于敌人前方；
- 条件满足后进入攻击起始，否则结束攻击意图并回到对峙。

### 7.3 攻击起始

- 进入该阶段前已经完成距离和前方检查；
- 立即对准玩家，防止攻击方向偏离；
- 启动配置技能 ID 对应的战斗逻辑；
- 使用基础动作配置中的动画名称播放攻击动画。

攻击起始阶段不重复进行距离和前方检查。

### 7.4 攻击进行

- 等待当前攻击动画结束；
- 预留后续扩展攻击窗口或其他阶段逻辑的位置；
- 玩家在此阶段按下攻击键时直接忽略，不缓存到攻击结束阶段。

### 7.5 攻击结束

处理顺序固定为：

1. 响应当前阶段收到的玩家攻击输入；
2. 闪避或防御触发时终止当前攻击和组合路线；
3. 未触发反应时检查组合动作；
4. 无组合、组合结束或续段条件失败时回到对峙。

## 8. 组合动作

首个基础动作进入攻击结束阶段后：

1. 用基础动作技能 ID 查询组合字典；
2. 若存在多个分支，按归一化概率选定一条完整路线；
3. 每进入下一段前重新检查玩家是否在敌人攻击范围内、是否位于敌人前方；
4. 条件失败时立即结束整个组合；
5. 条件满足时，下一段重新执行攻击起始、攻击进行和攻击结束；
6. 最后一段完成后结束攻击意图并回到对峙。

选定组合路线后不再重复投分支概率。

## 9. 玩家攻击输入与反应

### 9.1 输入来源

触发时机是玩家按下默认攻击键，不等待技能启动、攻击动画或伤害窗口。

反应距离使用玩家角色的默认攻击范围，不使用玩家当前技能的攻击范围，也不使用敌人的攻击范围。

### 9.2 输入状态限制

只在以下状态接受玩家攻击输入：

- 对峙；
- 攻击结束。

以下状态直接丢弃输入：

- 追击；
- 攻击起始；
- 攻击进行；
- 防御；
- 闪避；
- 中断状态。

### 9.3 空间条件

只有同时满足以下条件才进行反应检定：

- 敌人在玩家默认攻击范围内；
- 玩家位于敌人前方半区。

前方判断统一使用敌人水平朝向与目标水平方向的点积，点积不小于零表示位于前方。攻击续段、防御和闪避共用同一判断。

### 9.4 反应优先级

```text
稳定值低于 lowStabilityThreshold
    且 dodgeCooldown 已结束
    且 dodgeRate 检定成功
        => 闪避

未触发闪避
    且 defenseRate 检定成功
        => 防御

均未触发
    => 保持当前流程
```

每次玩家按键最多执行一次闪避检定和一次防御检定，禁止在 `Tick` 中重复投概率。

## 10. 防御与闪避生命周期

### 10.1 防御

- 防御开始时终止当前攻击意图和组合路线；
- 停止移动、面向玩家并播放防御动画；
- 动画自然播放结束后回到对峙；
- 防御命中进入中断层并播放 `DefenseHit`；
- 不修改现有防御伤害和稳定值结算。

### 10.2 闪避

- 闪避开始时终止当前攻击意图和组合路线；
- 闪避开始时记录冷却并开启无敌；
- 闪避动画期间不受伤且不播放受击动画；
- 动画结束或更高优先级中断时关闭无敌；
- 正常结束后回到对峙；
- 闪避冷却期间跳过闪避检定，但仍允许防御检定。

## 11. 配置校验

配置加载或编辑器校验必须快速失败：

- 每个近战敌人至少配置一个基础动作；
- 基础动作技能 ID 必须为有效值且不能重复；
- 动画名称不能为空；
- 基础动作权重不能为负，总权重必须大于零；
- 组合起始技能和序列中的每个技能必须存在于基础动作配置；
- 组合序列不能为空；
- 分支概率必须大于零；
- 同一起始技能允许存在多个组合分支；
- 无效配置必须明确报错，不能静默使用默认动作。

## 12. 测试与验收

### 12.1 配置测试

- 旧字段和旧逻辑已完全删除；
- 所有近战敌人配置迁移完成；
- 基础动作和组合动作合法性校验覆盖有效与无效配置；
- 组合字典按起始技能正确分组并归一化选择。

### 12.2 决策测试

- 稳定值不足时不能产生攻击意图；
- 稳定值满足时，攻击欲望和追击范围正确决定攻击意图；
- 欲望检定失败后等待决策冷却再检定；
- 玩家攻击输入只在对峙和攻击结束阶段有效；
- 反应判定使用玩家默认攻击范围；
- 闪避优先于防御，闪避失败后继续防御检定；
- 攻击进行阶段的输入被丢弃且不会延迟触发。

### 12.3 流程测试

- 攻击范围外执行追击，进入范围后开始攻击；
- 攻击按起始、进行、结束阶段推进；
- 基础动作按权重选择且每次攻击只选择一次；
- 组合动作按分支概率选路，每段前重新检查距离和前方；
- 防御动画结束后回到对峙；
- 闪避动画期间无敌，结束或中断时清除无敌；
- `DefenseHit` 和现有防御结算保持不变；
- 对峙状态现有 `MoveLeft/MoveRight` 表现不变。

### 12.4 项目验证

- 运行相关 EditMode 与 PlayMode 测试；
- 使用 AIBridge 执行 Unity 编译；
- 检查 Unity Error 日志；
- 在运行时验证追击、攻击阶段、组合分支、防御、闪避和无敌生命周期。

## 13. 已确认决策

- 采用“行为树调度 + 独立战斗决策器”架构；
- 对峙现有动画表现保持不变；
- 玩家攻击输入取自按键时刻，不跨攻击阶段缓存；
- 稳定值阈值同时控制攻击资格与闪避资格；
- 攻击结束阶段中，闪避和防御优先于继续组合动作；
- 防御和闪避结束后都回到对峙；
- 组合动作使用运行时字典索引；
- 旧配置与旧随机后撤逻辑全局删除；
- 当前没有待确认事项。
