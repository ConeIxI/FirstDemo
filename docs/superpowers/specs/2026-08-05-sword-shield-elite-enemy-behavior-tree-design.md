# 剑盾精英敌人行为树设计

## 背景

项目已创建剑盾精英敌人定义和行为树资产，但当前战斗逻辑复用了剑盾小兵的行为树。现有敌人战斗框架使用统一的 `defaultAttackRange`，基础攻击只配置 `skillId`、`animationName` 和 `weight`，无法表达不同技能的攻击范围，也无法区分基础攻击、进身攻击、追击攻击和防御反击。

本设计在保留现有四层行为树框架的基础上，引入配置驱动的攻击计划。剑盾精英使用独立行为树资产，通用节点和决策框架仍可被其他敌人复用。

## 目标

- 为每个全局技能增加唯一的最大攻击范围。
- 支持基础攻击、进身攻击、追击攻击、固定反击和锁定连招。
- 支持每类攻击配置多个候选技能并按权重选择。
- 让追击技能在选中后保持锁定，直到到达技能范围的 80% 再释放。
- 让防御中的第 2 次实际格挡触发待反击，并在当前防御受击动画结束后释放。
- 让剑盾精英拥有独立行为树资产，后续增加攻击动画时只需扩展配置。
- 迁移现有敌人到新框架，不保留统一攻击距离与攻击计划两套并行逻辑。

## 非目标

- 本期不增加单技能冷却。
- 本期不增加生命阶段、玩家失衡等组合攻击触发条件。
- 本期不改变玩家技能动画读取方式。
- 本期不为每种精英敌人创建独立战术代码类。
- 本期不将追击释放比例做成可配置参数。

## 核心方案

采用配置驱动的攻击计划方案：`EnemyCombatDecisionController` 根据配置、目标距离和当前战斗状态生成并锁定 `EnemyAttackPlan`，行为树负责准备和执行该计划。

行为树不直接访问全局技能配置，也不在多个节点中重复实现技能筛选规则。运行时启动阶段先将敌人攻击条目与全局技能配置关联成攻击目录，后续决策只读取该目录。

## 数据模型

### 全局技能配置

在 `SkillConfig` 中新增：

```csharp
public float attackRange;
```

`attackRange` 表示该技能能够覆盖的最大攻击范围，必须大于 `0`，是技能距离的唯一数据来源。

`SkillConfig.skillAnimationName` 保留，继续供玩家状态机使用。敌人战斗系统不再读取该字段，敌人的动画名始终来自敌人攻击条目。

### 敌人攻击条目

将 `EnemyBasicAttackConfig` 重构为通用的 `EnemyAttackConfig`：

```csharp
public sealed class EnemyAttackConfig
{
    public int skillId;
    public string animationName;
    public float weight;
}
```

该类型只描述敌人如何使用技能。伤害、稳定伤害、击退、打断和最大攻击范围仍由全局 `SkillConfig` 负责。

### 敌人战斗配置

`EnemyCombatConfig` 包含：

- `EnemyAttackConfig[] basicAttacks`
- `EnemyAttackConfig[] approachAttacks`
- `EnemyAttackConfig[] pursuitAttacks`
- `EnemyAttackConfig counterAttack`
- `EnemyComboBranchConfig[] comboBranches`
- `int counterBlockThreshold`
- 现有战斗进入范围、追击范围、战斗记忆和动作打断配置

删除以下字段：

- `defaultAttackRange`：基础近战边界改为基础攻击池内最大 `attackRange`。
- `specialSkillIds`：当前运行时未使用，由明确的攻击池和反击条目替代。
- `EnemyDecisionProfile.counterDesire`：反击改为确定性的格挡次数触发。

普通敌人的进身、追击和反击配置允许为空。配置了反击技能时，`counterBlockThreshold` 必须大于 `0`。

### 运行时攻击目录

敌人 AI 启动时，通过现有 `ConfigManager.GetSkillConfig(skillId)` 一次性构建 `EnemyAttackCatalog`。目录保存敌人攻击条目和对应全局技能范围，供决策器只读使用。

攻击目录构建失败时不启动 AI。缺少技能、非法范围或非法敌人攻击条目都由配置校验明确报告，不在战斗过程中使用默认值兜底。

### 攻击计划

`EnemyAttackPlan` 至少记录：

- 攻击类型：基础、进身、追击或反击
- 已锁定的敌人攻击条目
- 技能最大攻击范围
- 释放距离
- 准备方式：直接释放、普通接近或追击接近
- 已锁定的连招路线及当前位置
- 计划阶段：准备、执行或结束

`EnemyCombatDecisionController` 是攻击计划状态的唯一真相来源。黑板只镜像行为树条件和调试所需的技能编号、攻击类型与计划阶段。

## 决策规则

### 总优先级

战斗行为按以下顺序处理：

1. 死亡、失衡、受击等现有高优先级中断。
2. 防御和防御中的待反击。
3. 已锁定的连招或追击攻击计划。
4. 新攻击计划决策。
5. 普通战斗移动或对峙。

目标丢失、死亡、失衡或战斗层退出时，必须清空攻击计划、连招路线、格挡计数和待反击状态。

### 基础攻击

基础近战边界取 `basicAttacks` 中所有技能 `attackRange` 的最大值。

目标位于该边界内时，只保留 `attackRange >= 当前距离` 的基础攻击候选，再按 `weight` 选择。基础攻击仍受 `attackDesire` 和全局攻击决策冷却控制。

现有普通敌人迁移时，将原 `defaultAttackRange` 写入其现有技能的 `SkillConfig.attackRange`，从而保持原近战边界。

### 进身攻击

进身攻击的有效区间为：

```text
基础近战边界 < 当前距离 <= 进身技能 attackRange
```

同时要求目标仍在敌人的追击范围内。满足距离的进身技能进入候选池，再按 `weight` 选择。进身攻击继续受 `attackDesire` 和全局攻击决策冷却控制。

没有可用进身技能时，敌人继续使用现有普通接近或战斗对峙行为。普通接近可以为已选中的基础攻击移动到其完整攻击范围，不使用 80% 释放规则。

### 追击攻击

目标位于追击范围外时，从 `pursuitAttacks` 按 `weight` 选择一次并立即锁定，不受 `attackDesire` 和攻击决策冷却限制。

追击释放距离固定为：

```text
releaseDistance = attackRange * 0.8f
```

追击过程中不重新选择技能。达到释放距离且朝向有效后停止移动并释放。目标丢失或高优先级状态打断时取消计划。

追击池为空时，使用现有普通追击流程，不生成追击攻击计划。

### 组合攻击

组合攻击沿用 `EnemyComboBranchConfig`：起手技能由 `basicAttacks` 按权重选中，随后根据起手技能和分支概率锁定后续技能序列。

剑盾精英固定路线为：

```text
上挑 -> 左劈 -> 盾击 -> 跃击 -> 后撤
```

五段技能都存在于 `basicAttacks`，因此也允许脱离组合被独立选中，独立出现概率由各自的 `weight` 控制。只有上挑命中对应组合分支时才锁定完整路线。

每个后续技能开始前重新读取自己的 `attackRange` 并检查目标朝向。距离或朝向不满足时立即结束整套连招，不追近后续技能。

后撤仍是普通技能。它是否造成伤害由全局技能配置决定，武器碰撞是否开启由动画事件决定。

### 二连斩

二连斩是一个技能和一段动画。动画通过两组开启和关闭武器碰撞的事件形成两次独立命中窗口，不拆分为两个技能或两段连招。

### 防御反击

反击使用固定 `counterAttack`，不参与普通攻击权重池。

防御期间按实际成功格挡次数累计，而不是按玩家攻击输入次数累计。`EnemyCombatComponent` 使用待处理格挡次数而非单一布尔标记，避免同一帧或防御受击动画期间的多次格挡被合并丢失。

剑盾精英的 `counterBlockThreshold` 为 `2`：

1. 第 1 次实际格挡播放防御受击动画并继续防御。
2. 第 2 次实际格挡标记待反击，但不打断当前防御受击动画。
3. 当前防御受击动画结束后，重新检查目标距离与朝向。
4. 条件满足时先退出防御，再生成并执行固定反击计划。
5. 条件不满足时取消反击并结束防御。

反击命中是否打断玩家完全由该技能的 `InterruptConfig` 决定，不添加绕过统一战斗系统的强制打断逻辑。

## 行为树设计

剑盾精英保留独立资产目录，根节点继续使用四层响应式优先选择器：

1. `InterruptExecutor`
2. `CombatLayer`
3. `AlertLayer`
4. `NormalLayer`

精英 `CombatLayer` 的优先级为：

1. 转向目标。
2. 闪避反应。
3. 防御和待反击处理。
4. 执行已锁定攻击计划。
5. 生成并执行新攻击计划。
6. 普通追击或战斗待机。

### 节点职责

- 攻击意图生成节点重构为完整攻击计划生成节点，技能选择不再延迟到攻击执行阶段。
- 新增攻击计划准备节点。基础、进身和反击计划可以直接完成准备；普通接近计划移动到技能完整范围；追击计划移动到技能范围的 80%。
- `EnemyAttackFlowNodeAsset` 只负责激活技能、播放敌人侧动画、等待动画结束和衔接已锁定连招。
- `EnemyDefenseNodeAsset` 消费实际格挡次数，维护防御受击动画，并在满足条件后把待反击转换为攻击计划。
- 旧的统一攻击距离条件和仅服务于旧距离循环的资产在所有敌人迁移完成后删除。

剑盾精英行为树不得引用剑盾小兵目录内的可变战斗子树资产。两者可以引用同一套通用 C# 节点类型，但各自维护独立的行为树编排资产。

## 配置校验

配置校验必须覆盖：

- 每个全局技能的 `attackRange > 0`。
- 敌人攻击条目的 `skillId > 0`、动画名非空、权重大于 `0`。
- 基础攻击池非空。
- 每个攻击条目引用的全局技能存在。
- 每个候选池内部不存在重复技能。
- 反击技能不重复出现在普通、进身或追击池。
- 配置反击技能时，格挡阈值大于 `0`。
- 连招起手和所有后续技能均存在于 `basicAttacks`。
- 连招概率与攻击权重符合现有配置约束。

技能激活或动画启动在运行时失败时，当前攻击计划必须明确失败并清理，不能保留半完成状态。合法的能力标签拒绝属于正常战斗结果，不作为配置异常吞没。

## 资产与数据迁移

1. 为所有现有技能配置补齐有效 `attackRange`。
2. 将全部敌人定义从 `EnemyBasicAttackConfig` 迁移到 `EnemyAttackConfig`。
3. 删除敌人定义中的 `defaultAttackRange` 和 `specialSkillIds`。
4. 删除决策配置中的 `counterDesire`，增加 `counterBlockThreshold`。
5. 将现有普通敌人的特殊攻击池保持为空，并迁移到攻击计划行为树流程。
6. 在当前未提交的剑盾精英资产基础上构建独立行为树，不回滚或覆盖用户已有配置。
7. 删除迁移后无引用的旧距离节点资产和旧行为树分支，避免双轨配置。

## 验收标准

- 剑盾精英运行独立行为树，不再复用剑盾小兵的可变战斗子树资产。
- 每个技能都有有效的全局最大攻击范围，敌人决策不再读取统一 `defaultAttackRange`。
- 突刺、快速飞跃、反击、二连斩和五段组合均按本文规则触发和结束。
- 追击技能选中后不会在追击过程中重新抽取。
- 防御反击只统计实际格挡，并在第 2 次格挡对应的防御受击动画结束后尝试释放。
- 新增攻击动画和技能时不需要修改行为树代码或增加硬编码数量分支。
- 普通敌人迁移后原有战斗表现不发生非预期变化。
- Unity 编译与相关自动化测试全部通过。
