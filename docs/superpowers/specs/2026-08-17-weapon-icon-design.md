# 武器图标设计

## 目标

根据用户提供的长剑参考图，生成一张与 `Assets/Res/UI/Atlas/Equip` 现有装备图标风格一致的武器图标。

## 画面规格

- 画布尺寸：128×128 像素。
- 背景：透明，不添加底框、文字或场景。
- 构图：长剑从左下指向右上，主体尽量占满方形画布，同时保留完整剑尖和剑柄轮廓。

## 造型与风格

- 保留参考图的窄长双刃剑身、微弧护手、深色皮革握柄和金属配重头。
- 使用与现有装备图标一致的偏写实手绘表现。
- 金属以银灰色为主，使用明确高光、深色阴影和少量暖色轮廓光强化剪影。
- 材质细节清晰但不过度繁复，不添加宝石、符文、魔法光效或额外装饰。

## 交付与验收

- 输出为带透明通道的 PNG 文件，保存到 `Assets/Res/UI/Atlas/Equip`。
- 缩放到 128×128 后，剑身、护手和握柄仍能清晰辨认。
- 图标边缘干净，无白底、明显光晕、水印或文字。
- 视觉密度、明暗对比和渲染精度与同目录现有装备图标协调。
